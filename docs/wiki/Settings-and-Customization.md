# Settings & Customization — Gould

> **Releases:** [0.12 Stable](https://github.com/stokonn/Gould/releases/tag/v0.12) · [0.13 Project Renaissance (pre-release)](https://github.com/stokonn/Gould/releases/tag/v0.13). **0.13 is not Stable.**

Choose Czech, English or system language, supported Ivory/Nocturne appearance, typography and layout preferences. Online catalogue/provider search requires separate opt-in; downloaded media has its own settings and storage controls.

## Data & Storage

Export format-6/schema-11 portable JSON backups. Formats 1–5 remain importable. JSON includes recording metadata, **not audio bytes**: use the optional media ZIP to transfer saved and recoverable audio. Exports are unencrypted and a document provider may synchronize them; store them carefully. Restore validates the data and requires explicit confirmation. Keep original backups and unresolved recovery material. CSV reports and diagnostic exports are not interchangeable with portable backups.

## Privacy and microphone

Experimental Smart Practice analyzes transient microphone input locally. Continuous WAV recording requires an explicit Record action. Recordings remain local unless exported. Optional Google profile sign-in is not practice synchronization. Community uploads, backend OAuth and journal uploads remain disabled. Read the [privacy notice](https://github.com/stokonn/Gould/blob/main/docs/PRIVACY.md).
