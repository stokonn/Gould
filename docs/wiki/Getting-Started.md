# Getting Started — Gould

> **Current releases (November 2026):** [Gould 0.12 Stable](https://github.com/stokonn/Gould/releases/tag/v0.12) · [Gould 0.13 — Project Renaissance (pre-release)](https://github.com/stokonn/Gould/releases/tag/v0.13). Version 0.13 is not Stable.

Download the APK for your preferred channel from [GitHub Releases](https://github.com/stokonn/Gould/releases): use **0.12** for the latest Stable release or **0.13** if you deliberately want the newer pre-release. Android 8.0+ is required.

Before updating, export a backup using **Settings → Data & Storage** and keep it outside app-private storage. Install the signed APK over the existing compatible app; the application ID remains `com.opus.piano`. If Android reports a signing or version error, **do not uninstall** to work around it—preserve the installation and data instead.

Your repertoire, practice history and recordings stay local. Library and Discover work with local catalogue data, while optional online provider search requires consent in Settings. Google profile identity is optional and does not synchronize the journal.

To begin, add a piece in Library, open Studio/Practice and explicitly start a session. Smart Practice uses the microphone only when enabled; manual practice works without it. Recording requires a separate explicit action. For backups and recording transfer, see [Settings & Customization](Settings-and-Customization) and [User Guide](User-Guide).
